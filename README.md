Assignment 2 – Data Cleaning and Transformation
📌 Project Overview

This assignment focuses on data cleaning and transformation using Excel. The objective is to prepare raw data for analysis by identifying and handling data quality issues and applying appropriate transformations.

The cleaned dataset can then be used for further analysis, reporting, and visualization.

📂 Files Included
Assignment 2 - Data Cleaning and Transformation work file.xlsx – Excel workbook containing the data cleaning and transformation work.
README.md – Documentation describing the assignment and the work completed.
🛠️ Tools Used
Microsoft Excel
GitHub
🔄 Data Cleaning & Transformation

The following data preparation activities were performed as part of the assignment:

Identified and handled missing or blank values
Checked for duplicate records
Corrected inconsistent data formats
Standardized data values where required
Cleaned text and categorical fields
Converted data into appropriate formats
Applied transformations required for analysis
Reviewed the final dataset for consistency and accuracy
🎯 Objective

The main objective of this assignment is to demonstrate the ability to:

Understand raw datasets.
Identify common data quality problems.
Clean and standardize data.
Transform data into a usable format.
Prepare a reliable dataset for further analysis.
📊 Final Output

The final Excel workbook contains the completed data cleaning and transformation work.

The cleaned and transformed data is ready to be used for subsequent data analysis and visualization tasks.
